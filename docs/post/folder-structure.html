my-tech-memoir folder structure

Muted files are frontend — anything a normal Next.js UI app would have (pages, components, i18n, theme, config, docs). Ambiguous files count as frontend. Highlighted files are backend — they exist because this app has a database, auth against that database, and HTTP APIs. You write prisma/schema.prisma and prisma/seed.ts. Files tagged prisma auto generated come from prisma generate, prisma migrate, or prisma init.
